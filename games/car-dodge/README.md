# 🚗 Car Dodge

Jogo simples de navegador desenvolvido com **HTML, CSS e JavaScript puro**.

## 🎮 Como jogar

1. Abra o arquivo `index.html` no navegador.
2. Clique em **Começar jogo**.
3. Use **← →** ou **A / D** para mover o carro.
4. Desvie dos carros inimigos.
5. Tente conseguir a maior pontuação possível.

## 🧠 O que o projeto demonstra

- Manipulação do DOM
- Eventos de teclado
- Canvas API
- Game loop com `requestAnimationFrame`
- Detecção de colisão
- Arrays e objetos em JavaScript
- `localStorage` para salvar o recorde
- Design responsivo
